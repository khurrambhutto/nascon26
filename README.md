# ArenaOne — NaSCon 2026 Part I

Self-hosted multi-sport leagues, append-only scoring, standings, club rosters and a concurrency-safe merchandise store.

## Run the backend

Set the organizer-provided `DAY1_SALT` in your shell; never commit the real value.

```sh
export DAY1_SALT='your-team-slip-value'
docker compose up -d --build
curl http://localhost:8080/health
```

PowerShell: `$env:DAY1_SALT = 'your-team-slip-value'`, then run the same Docker command.
The API listens on **8080**. OpenAPI documentation: `http://localhost:8080/docs`.
Postgres, Redis Streams, MinIO and the outbox worker are self-hosted. Database schema and demo content initialize automatically.
`POST /audit/v1/reset` replaces all competition state and recreates baseline/demo data.

The booklet's unavailable MinIO image is replaced with `bitnamilegacy/minio:2024.9.22`; notify the organizers of this compatibility substitution.

## Backend tests

```sh
cd backend
uv venv --python 3.12
uv pip install -r requirements.txt
cd ..
./run_tests.sh
```

On Windows use `backend/.venv/Scripts/python.exe -m pytest backend/tests -q`.
Unit tests use an isolated SQLite database; deployment uses PostgreSQL with a database-backed lock for atomic domain mutations.
Coverage figures in `COVERAGE.json` are generated by `tests/write_coverage.py`, not manually estimated.

## Mobile

The frontend agent owns `mobile/`; build and release instructions are maintained there and in `PLAN.md`.
Use `http://10.0.2.2:8080/` on the emulator or the backend laptop's LAN address on a phone.

## Architecture

Domain modules are separated into scoring, standings, fixtures, roster, store, authorization and offline synchronization.
PostgreSQL persists domain records in JSON with a global transaction mutex. This deliberately simple design serializes mutations across API processes, prioritizing correctness at competition scale over independent parallel writes.
An order and its durable outbox event commit together. The worker publishes order events to Redis Streams and archives receipts in MinIO; receipt PDFs are returned synchronously by checkout.
Match SSE streams detect committed changes every second and send `event: update`; the mobile contract also permits a three-second polling fallback.

For deployment outside the competition, replace demo credentials/secrets and restrict the audit/reset interface to a trusted evaluation network.
